Run the AI agent demo

The stream template ships a JSON tool interface for AI agents. Press the button and its three tool calls run for real from your wallet on Arbitrum Sepolia: open a stream of 10 test BUIDL, pay out what has been earned after a few seconds, then cancel and split the rest. Under each call is the exact JSON the agent gets back, with the transaction on Arbiscan. The page runs a port of the agent's own code, and CI checks every result against the agent CLI's output, field by field.

open_stream→wait→withdraw_from_stream→cancel_stream
Needs a wallet with a little Arbitrum Sepolia ETH and 10 BUIDL (free from the faucet). Your wallet asks 3 or 4 times; about a minute in all.

      Stylus vs Solidity: measured gas

      The counter template and a line-for-line Solidity twin, deployed to the same Arbitrum Nitro node and sent identical transactions. Execution gas from the receipts (gasUsed − gasUsedForL1), uncached. Stylus pays a fixed cost to enter WASM, so plain storage calls cost about 2× more; real computation costs about 31× less. Pick it for compute-heavy logic, not as a free win everywhere.

      Deploy your own

      Every contract above came out of one command. Scaffold the same thing, try it on a free local node, then deploy it.

      npx create-stylus-latest my-stream -t stream --with-client
cd my-stream && cargo test                    # unit + property tests
cp .env.example .env && ./scripts/devnode.sh  # local Nitro node, funded key, Stylus deployer
RPC_URL=http://127.0.0.1:8547 ./scripts/deploy.sh -- 0xYourTokenAddress

      What you get

      ⚡

      Always current

      Reads the crates.io index at scaffold time and pins the newest stable SDK with the exact alloy version it needs. Works offline with a known-good fallback.

      🧱

      Nine templates

      counter, erc20, erc721, vault, escrow, stream, oracle (Chainlink), interop (Solidity calling Rust) and faucet. Every one except the counter has unit tests and a property test: every token movement against a reference model, every price against the oracle rules, every mulDiv against its 512-bit definition.

      🤖

      Agent-native

      Stream, escrow, vault and faucet ship a JSON tool interface an AI agent can call, with spending limits enforced before signing and the contract's own error names in every failure. The same tools are an MCP server, so Claude Desktop, Claude Code or Cursor can use the contract directly.

      🚀

      Deploy that works

      deploy.sh handles the lockfile, RPC override, gas cap and key hand-off. devnode.sh starts a local Nitro node for free validation. VERIFY=1 deploys reproducibly, and verify.sh proves the deployed code is your source.

      💻

      Typed client

      --with-client adds a viem script that fails loudly on reverted transactions.

      💵

      USDG & Robinhood

      --usdg wires vault, escrow and stream to Paxos USDG; --network targets Arbitrum or Robinhood Chain. Addresses checked on-chain in CI; mainnet deploys need MAINNET=1.

      How it was verified

      1. Every template is built, tested and validated against a local Nitro node in CI, using live crates.io versions.
      2. An end-to-end CI job deploys a generated contract and calls it through the generated client.
      3. The same flow was then run against Arbitrum Sepolia, producing the contracts above.
      4. A Solidity contract calls the interop template's Rust library on a Nitro node, and catches its errors by name.
      5. A reproducible deploy is verified against its source, and a one-line change to that source must fail verification.
      6. The official MCP SDK client drives the MCP server against real contracts: it opens and cancels a stream, and a spending limit refuses with the CLI's exact JSON.

      These are templates, not audited contracts. Do not hold real funds in them.
