Scaffold a Stylus project that deploys on the first try.

create-stylus-latest generates a Rust smart contract project for Arbitrum, pinned to the newest stylus-sdk and its matching alloy version, with deploy scripts that have been run on a live network.

git clone https://github.com/ramadan904/npx-create-stylus-latest
cd npx-create-stylus-latest
node bin/create-stylus-latest.js my-app -t counter --with-client

Live on Arbitrum Sepolia

Three contracts scaffolded by this tool and deployed with its own scripts. The values below are read from the chain in your browser right now.

What you get

Always current

Reads the crates.io index at scaffold time and pins the newest stable SDK with the exact alloy version it needs. Works offline with a known-good fallback.

Three templates

counter, erc20 and vault (a stablecoin vault using cross-contract calls), each with unit tests.

Deploy that works

deploy.sh handles the lockfile, RPC override, gas cap and key hand-off. devnode.sh starts a local Nitro node for free validation.

Typed client

--with-client adds a viem script that fails loudly on reverted transactions.

How it was verified

  1. Every template is built, tested and validated against a local Nitro node in CI, using live crates.io versions.
  2. An end-to-end CI job deploys a generated contract and calls it through the generated client.
  3. The same flow was then run against Arbitrum Sepolia, producing the contracts above.

These are templates, not audited contracts. Do not hold real funds in them.
